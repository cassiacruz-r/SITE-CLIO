# Clio — Website

Website desenvolvido para a Clio, atualmente em desenvolvimento.

O projeto foi criado como uma proposta de presença digital para a marca, explorando estrutura visual, identidade e experiência de navegação.

## Status

Em desenvolvimento.

O projeto ainda não está finalizado e pode receber alterações de layout, conteúdo, funcionalidades e identidade visual.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Estrutura do projeto

```text
SITE-CLIO/
├── css/
├── js/
└── index.html
```

## Objetivo

Desenvolver um website institucional para a Clio, com uma interface moderna, responsiva e alinhada à identidade da marca.
